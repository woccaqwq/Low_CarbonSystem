# 迭代二模块十三 设计图与接口同步

本模块对齐当前 Java 源与迭代一设计，交付 [迭代二设计图册](../design/iteration2/README.md)，保留原 Word、PNG 和 SQL。

## 已同步内容

- 三张类图：领域关系、DAO/连接与查询、会话/配置/统计/异常/文件工具。
- 六张接入时序图：登录、检索、确认成交、评价、统计与 CSV、管理员违规下架。
- 一张状态图，区分实体状态守卫与 DAO 条件更新。
- 从 Java 源提取的九 DAO 完整 112 个方法（56 普通、56 连接重载），以及十六实体字段清单。
- [接口变更与交接记录](../design/iteration2/interface-changes.md)，包括新增对象、返回语义、事务模板更正及待共同明确的设计事项。

各图提供 SVG/PNG 预览与 Mermaid 源；类图/状态图另有 DOT，时序图另有 JSON 模型，便于继续编辑。生成工具不写业务数据库，不依赖 Maven 新包。

## 实现状态

类图中的类型已有代码，方法只展示名称摘要，精确签名以自动生成清单为准。时序中的黄色虚线参与者表示未实现的 Service/GUI；成功与回滚路径是接入设计，不是本轮新增业务代码。
流转与评价的参与人、期限、权限等业务校验仍待 Service；运行日志与 CSV 也没有自动接入 App。完整职责与限制见图册说明。

## 验证

```powershell
node scripts/render-iteration2-diagrams.cjs --check
```

校验范围为类型/方法引用、成对连接重载、实现与工厂映射、生成文本、时序分支/参与者和图片存在性。另需逐图检查布局与独立核对业务语义；不将此校验当作 Mermaid 引擎、Java 编译或业务单元测试。
已完成十张预览的布局检查和独立只读核对；按核对意见明确取消其他意向允许返回 0，并细化 CSV 清理失败的 suppressed 语义。图与清单已重新生成校验。
本模块没有修改 Java/SQL，没有新增业务测试，也没有重跑 Maven。253 项通过属于模块十二代码基线 `1b3ae6f` 的已验证结果。
