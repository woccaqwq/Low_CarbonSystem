# User Data Module Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 实现可供成员 2 的 UserService 调用的用户存取和口令工具。

**Architecture:** 复用模块一 DBUtil；UserDao 保留冻结的八个普通方法，新增 Connection 重载用于事务。
BaseDao 负责参数绑定、资源关闭、映射与异常转换，业务权限、登录锁定和密码强度规则由 Service 负责。

**Tech Stack:** Java 17，SQLite JDBC 3.47.1.0，JUnit 5.11.4，Maven。

**Spec:** 文本文档/02_迭代1_系统设计说明书.docx 第 4.2、4.4、5、8、10 章；初始化脚本中的 sys_user 与 PBKDF2 参数。

## Global Constraints

- 保留 UserDao 八个普通方法的名称、参数和返回类型；单条插入返回主键，更新返回受影响行数。
- PBKDF2WithHmacSHA256，100000 次，256 位输出，16 字节随机盐；哈希和盐使用 Base64。
- LocalDateTime 与 SQLite yyyy-MM-dd HH:mm:ss 互转；last_login_at 允许 null。
- PageResult 不可变，页码从 1 开始，pageSize 10–100；非法分页参数在 DAO 拒绝，Service 可提前校正。
- 普通 DAO 方法管理自己的连接；Connection 重载不关闭、提交或回滚调用方连接。
- 延续当前 feature/iteration2-data 分支与已有未提交模块一；本轮不自动提交、推送或合并。

## Review Focus

- 初始账号哈希兼容性：三个初始账号应通过验证，错误口令应失败。
- 非法 Base64 或错误长度的凭据：验证返回 false；派生入口拒绝错误盐。
- 搜索中的引号、百分号、下划线和反斜杠按普通文本处理，不影响 SQL 结构。
- pageNo 或信用分增量取 Integer.MAX_VALUE / MIN_VALUE 时不发生整数溢出。
- 外部事务失败后，插入、密码、信用分、状态和登录时间应可整体回滚。
